# BankLedger Pro

اپلیکیشن اندرویدی ثبت هوشمند تراکنش‌های بانکی با تمرکز روی سادگی و ظاهر حرفه‌ای.

## امکانات نسخه اول
- دریافت پیامک تراکنش و تشخیص واریز/برداشت
- تشخیص چند بانک ایرانی + امکان بانک سفارشی
- ثبت توضیح برای هر تراکنش
- ویرایش و حذف تراکنش
- انتخاب نمایش ریال یا تومان
- داشبورد روزانه، هفتگی و ماهانه
- موجودی حساب و تشخیص موجودی از پیامک در صورت وجود
- ثبت دستی تراکنش
- آموزش/نمونه پیامک بانک برای بهبود تشخیص
- سایدبار کشویی حرفه‌ای
- ذخیره اطلاعات با Room

> نکته Android: سیستم‌عامل‌های جدید محدودیت‌هایی برای باز کردن Activity از پس‌زمینه دارند. برنامه برای پیامک ورودی یک اعلان فوری و قابل لمس می‌سازد و تراکنش را در صف نگه می‌دارد؛ وقتی برنامه در foreground باشد، پنجره ثبت توضیح نمایش داده می‌شود.

## ساخت
در GitHub Actions workflow پروژه، APK دیباگ ساخته و به عنوان Artifact منتشر می‌شود.
